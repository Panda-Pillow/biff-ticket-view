권장 등록명
나의 상영 일정 — BIFF 예매 도우미 (비공식)

짧은 설명
BIFF 예매 목록을 관람일별로 모아 보고, 상세보기 후에도 필터와 보던 위치를 이어가세요. 비공식 도구입니다.

언어: 한국어
분류 제안: 생산성 / 워크플로와 계획에 가장 가까운 현재 대시보드 항목

상세 설명 — 아래부터 붙여 넣기

예매한 영화를, 내가 볼 순서대로.

여러 페이지에 나뉜 BIFF 예매 내역을 날짜별로 모아 보세요. 상세보기에서 돌아왔을 때도 선택한 필터와 보던 위치를 이어갈 수 있습니다.

이 확장 프로그램은 개인이 제작한 비공식 도구입니다. 부산국제영화제(BIFF) 및 예매 시스템 운영사와 제휴하거나 이들의 승인을 받은 제품이 아닙니다.

■ 날짜별로 한눈에
선택한 관람 월의 예매 목록을 모든 페이지에서 불러와 날짜와 시간순으로 정리합니다. 날짜 버튼에서 해당 날짜의 예매 건수를 확인하고 원하는 하루만 골라 볼 수 있습니다.

■ 필요한 영화를 빠르게
영화 제목 검색, 상영관 필터, 관람일 빠른순·늦은순 정렬을 제공합니다. 예매내역과 취소내역도 전환할 수 있습니다.

■ 상세보기 후에도 이어서
같은 탭에서 조회 월, 날짜, 검색어, 상영관, 정렬과 보던 위치를 기억합니다. 상세보기에서 목록으로 돌아오면 최신 내역을 다시 읽고 위치를 복원합니다. 취소한 항목이 사라졌다면 기존 목록의 다음 항목, 없으면 앞 항목을 기준으로 복원합니다.

■ 익숙한 공식 화면으로 연결
상세 확인과 취소는 기존 예매 사이트에서 진행합니다. 확장 프로그램은 자동 예매나 자동 취소를 하지 않습니다. 조건에 맞는 HTTPS 모바일티켓 링크가 제공되는 경우 바로 열 수 있습니다.

■ 목록에 집중하는 화면
예매 목록 하단의 회전 배너와 푸터를 숨깁니다. ‘원래 화면 보기’를 누르면 기존 목록을 다시 볼 수 있습니다. 원래 목록으로 전환해도 하단 배너·푸터 숨김은 유지됩니다.

사용 방법
1. 데스크톱 Chrome에 확장 프로그램을 설치합니다.
2. BIFF 예매 사이트에 로그인하고 ‘예매 확인/취소’ 목록을 엽니다.
3. ‘나의 상영 일정’에서 조회할 관람 월과 날짜를 선택합니다.

개인정보 처리
목록을 구성하기 위해 로그인된 예매 서비스에서 영화명, 관람 일시, 상영관, 수량, 예매 상태, 예매번호 및 제공되는 모바일티켓 링크를 읽습니다. 위치 복원을 위해 조회 조건과 예매번호·목록 순서를 해당 탭의 sessionStorage에 임시 저장합니다. 개발자 서버로 예매 데이터를 전송하지 않으며 광고·분석·추적 도구를 포함하지 않습니다. 조회 요청은 기존 로그인 세션을 사용해 원래 예매 서비스로 전송됩니다.

이용 범위
• 현재 선택한 관람 월을 기준으로 조회합니다. 여러 달을 한 번에 합치지는 않습니다.
• 상태 복원은 같은 탭 기준이며 기기 간 동기화 기능은 없습니다.
• 좌석, 취소 가능 여부, 수수료와 환불 정보는 공식 상세 화면에서 확인해 주세요.
• 사이트 구조나 API가 변경되면 일부 기능이 작동하지 않을 수 있습니다.
• 원래 사이트의 데이터·취소 규정·서비스 정책은 이 확장 프로그램과 별개입니다.
