1. 적용 범위와 목적

이 확장 프로그램은 BIFF 예매 사이트에서 예매 내역을 관람일별로 정리하고, 같은 탭의 조회 조건과 위치를 복원하며, 예매·취소 상세내역과 예매하기 화면의 배치를 개선하는 비공식 도구입니다. 사용자가 요청하면 개인용 티켓 목록 HTML 파일을 저장하거나, 이전에 내려받은 여러 목록을 하나로 합칩니다. 부산국제영화제 및 예매 시스템 운영사와 제휴하거나 이들의 승인을 받은 제품이 아닙니다.

2. 처리하는 정보

확장은 예매 서비스의 목록 API 응답에서 다음 정보를 사용합니다.
• 영화명, 관람 날짜와 시간, 상영 장소·상영관
• 예매번호, 예매일시, 예매 수량, 예매·취소·입금대기 상태
• 모바일티켓 링크 및 그 표시 여부 판단에 필요한 발권·취소 수량과 수령 방식
• 조회 월, 예매내역/취소내역 구분, 선택한 날짜, 영화명 검색어, 상영관, 정렬 방식, 원래 화면 보기 설정
• 보던 위치를 식별하는 예매번호, 표시 중인 예매번호의 순서, 스크롤 위치와 항목의 화면 내 위치

원래 API 응답에는 서비스가 제공하는 다른 필드가 포함될 수 있습니다. 응답은 브라우저 메모리에서 읽히며 확장의 목록 모델에는 기능에 사용하는 필드만 남깁니다. 실제 이름·이메일·전화번호·결제카드 정보를 요구하거나 이를 조회하기 위한 별도 API를 호출하지 않습니다. API가 이런 필드를 전혀 반환하지 않는다고 보장하는 것은 아닙니다. 예매·취소 상세내역에서는 원래 사이트에 표시된 예매자·좌석·결제 등 정보의 배치와 스타일을 조정하며, 이를 다운로드 목록에 추가하거나 개발자 서버로 전송하지 않습니다.

목록을 내려받을 때 사용자가 입력하는 1~80자의 계정 구분명을 처리합니다. 구분명은 티켓을 열 때 사용할 계정을 사용자가 알아보기 위한 표시용 이름입니다. 실제 로그인 아이디·이메일·전화번호·비밀번호를 입력할 필요는 없습니다. 확장은 계정을 자동으로 탐지·인증·전환하지 않습니다.

‘티켓 목록 합치기’에서는 사용자가 직접 선택한 HTML 파일의 내용과 파일명을 브라우저 안에서 읽습니다. 파일명은 선택 목록에 표시하고, 파일 안의 상영 정보·예매번호·예매일시·매수·모바일티켓 링크·저장된 계정 구분명을 읽어 합칩니다. 계정 구분명이 없는 이전 파일에는 사용자가 직접 구분명을 지정합니다. 파일명에서 계정 정보를 추론하지 않습니다.

3. 사용 목적

정보는 날짜별 목록 표시, 제목 검색·상영관 필터·정렬, 공식 서비스의 예매 상태 조회, 상세 화면 및 모바일티켓 연결, 같은 탭의 조회 상태와 위치 복원, 개인용 HTML 파일 생성과 목록 합치기에 사용합니다. 계정 구분명은 저장한 목록에서 계정을 구별하고 다시 합칠 때 그 구분을 유지하는 데 사용합니다.

저장하거나 합친 목록은 저장 시점의 정보이며 현재 예매·취소 상태를 자동으로 갱신하지 않습니다. 합치기는 티켓 양도나 계정 접근 권한 이전 기능이 아닙니다. 다른 사이트의 방문 기록 수집, 광고 대상자 선정·사용자 프로파일링에는 사용하지 않으며 확장 사용 분석, 오류 로그 수집, 광고 SDK도 포함하지 않습니다.

4. 저장 위치와 보관 기간

조회한 예매 목록과 모바일티켓 링크는 페이지 메모리에서 처리하며 개발자가 운영하는 서버나 데이터베이스에 저장하지 않습니다. 브라우저의 뒤로가기 캐시가 페이지 메모리를 일시 유지할 수 있습니다.

조회 조건과 위치 복원용 예매번호·목록 순서는 예매 사이트 출처의 sessionStorage에 저장합니다. 이는 웹사이트와 공유되는 탭 단위 저장소이며 확장 전용 비밀 저장소가 아닙니다. 일반적으로 탭 세션 종료 시 정리되지만 브라우저의 닫은 탭 복원·세션 복원에 따라 다시 복원될 수 있습니다. Chrome Sync, chrome.storage.sync, localStorage를 통한 영구 동기화는 사용하지 않습니다.

사용자가 다운로드하면 영화명, 관람 날짜·시간, 상영관, 예매번호, 예매일시, 매수, 예매완료 상태, 모바일티켓 링크와 계정 구분명이 포함된 HTML 파일을 기기에 저장합니다. 파일에는 저장 시각과 조회월 또는 해당 기간도 포함됩니다. 다운로드는 현재 검색·필터와 관계없이 조회월의 예매완료 티켓 전체를 포함합니다. 생성된 파일은 사용자가 삭제할 때까지 남으며 확장을 제거하거나 사이트 데이터를 삭제해도 자동으로 삭제되지 않습니다.

합치기 화면에서 선택한 파일 내용과 구분명은 브라우저 메모리에서 처리합니다. 원본 파일을 실행하거나 덮어쓰지 않고 필요한 정보를 읽어 새 HTML 파일을 생성합니다. 합친 파일에도 계정 구분명과 티켓 링크가 남습니다. 합치기 화면을 닫거나 새로고침하면 화면의 작업 상태를 다시 불러오는 별도 영구 저장 기능은 없습니다.

sessionStorage와 다운로드 HTML에는 별도의 애플리케이션 수준 암호화나 암호 잠금을 적용하지 않습니다. 파일을 열 수 있는 사람은 포함된 정보를 읽을 수 있습니다. 사용자가 파일을 클라우드 동기화 폴더에 저장하거나 다른 앱으로 옮기면 해당 서비스의 보관·동기화 정책이 별도로 적용됩니다.

5. 네트워크 요청과 정보 전달

확장은 HTTPS로 filmapi.maketicket.co.kr의 예매 목록 API에 조회 월, 조회 기준, 내역 구분, 페이지 범위 및 언어 값을 보냅니다. credentials: include 요청으로 브라우저가 기존 예매 서비스의 로그인 세션을 해당 서버에 전달할 수 있습니다. 확장이 비밀번호나 쿠키 값을 직접 읽어 개발자에게 보내는 구조는 아닙니다.

상세 링크를 누르면 예매번호가 포함된 biff.maketicket.co.kr의 원래 상세 주소로 이동합니다. 모바일티켓 링크를 누르면 tket.me의 해당 티켓 주소를 새 탭에서 엽니다. 공식 티켓을 열려면 인터넷 연결과 해당 계정의 로그인이 필요할 수 있습니다. 다운로드 파일은 QR코드나 오프라인 입장권을 저장하는 기능이 아닙니다.

파일 생성과 합치기는 브라우저 안에서 처리하며 이를 위해 파일 내용·파일명·계정 구분명을 서버로 업로드하지 않습니다. 개발자가 운영하는 수집 서버는 없으며 예매 데이터·조회 조건·위치 정보·계정 구분명을 개발자나 광고·분석 사업자에게 전송·판매하지 않습니다. 사용자가 파일을 다른 사람에게 전달하면 포함된 예매 정보와 티켓 링크도 함께 전달됩니다.

원래 사이트와 티켓 서비스는 직접 통신 과정에서 IP 주소, 요청 정보, 로그인 세션 등을 자체 정책에 따라 처리할 수 있습니다. 원래 사이트가 독립적으로 운영하는 분석·쿠키까지 이 확장이 차단하거나 관리하지는 않습니다.

6. 사용자의 제어와 삭제

확장을 끄거나 삭제하고 열려 있는 예매 페이지를 새로고침하면 확장의 추가 동작을 중지할 수 있습니다. ‘원래 화면 보기’는 화면 전환이며 저장 데이터 삭제나 모든 조회 중단을 의미하지 않습니다. ‘필터 초기화’는 화면 조건을 초기화하며 모든 저장 정보를 삭제하는 기능은 아닙니다.

저장된 조회 상태를 제거하려면 확장을 끄고 예매 사이트의 저장 데이터를 브라우저 설정에서 삭제해 주세요. 사이트 데이터 삭제는 원래 사이트의 로그인 상태에도 영향을 줄 수 있습니다. 확장 삭제만으로 웹사이트의 sessionStorage까지 즉시 삭제된다고 보장하지 않습니다.

다운로드 시 계정 구분명 입력을 취소하면 파일을 생성하지 않습니다. 저장한 원본·합친 HTML 및 휴대폰·클라우드 등으로 복사한 파일은 각 저장 위치에서 직접 삭제해 주세요. 이미 다른 사람에게 전달한 사본을 확장이 원격으로 삭제할 수는 없습니다. 티켓 상태나 계정 구분명을 변경하려면 올바른 정보로 목록을 다시 내려받고 불필요한 이전 파일을 삭제해 주세요.

예매 취소·환불 또는 예매 서비스가 보유한 정보의 열람·삭제는 원래 서비스에서 처리합니다. 확장은 예매를 자동 취소하거나 원래 서비스의 계정 데이터를 삭제하지 않습니다.

7. 제한된 사용

이 확장은 Chrome 웹스토어 사용자 데이터 정책의 제한된 사용(Limited Use) 요구사항에 따라 정보의 사용 및 원래 서비스와의 전달을 위에서 설명한 사용자 기능 제공에 한정합니다. 광고, 데이터 판매, 신용도 판단 또는 대출 심사에 사용하지 않습니다. 개발자가 사용자의 예매 데이터나 로컬 파일을 원격으로 열람하는 기능은 없습니다.
